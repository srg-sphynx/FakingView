First FakingView public beta: a native Rust charting workspace for macOS with a
personal Kite Connect market-data integration and an independent application identity.

### Included

- Indian exchange search, historical OHLCV charts and WebSocket watchlist quotes.
- Daily Kite login/token exchange, platform secret-store persistence, typed errors,
  rate limits, instrument refresh and stale-quote handling.
- INR chart headers, Pine Studio previews and provider routing through watchlists,
  Pine requests and MCP market access.
- FakingView icons, bundle/storage identities, setup guides, specifications,
  sample-data screenshots and social artwork.

### Download and install

Download **FakingView-v0.1.0-beta.1-macos-arm64.zip**, extract it, and move
`FakingView.app` to Applications. Requires **Apple Silicon and macOS 14+**.
This beta is **not Developer ID signed or notarized**. Follow the
[installation guide](https://github.com/srg-sphynx/FakingView/blob/v0.1.0-beta.1/docs/getting-started.md)
for macOS approval and Kite configuration.

Verify the downloads with the attached `SHA256SUMS.txt`:

```sh
shasum -a 256 -c SHA256SUMS.txt
```

`FakingView-v0.1.0-beta.1-source.tar.gz` contains the corresponding GPL source
from this release's tagged commit. Required copyright and third-party notices
are included in the source and app bundle.

### Verification and limits

Local checks: **7,841 passing tests, no failures, 131 ignored optional tests**;
formatting and all-target/all-feature Clippy passed. Real application screenshot
galleries were also rendered and reviewed. See the
[verification record](https://github.com/srg-sphynx/FakingView/blob/v0.1.0-beta.1/docs/verification.md)
and repository Actions for scope and CI results.

Live Kite authentication, data entitlement and market-hours streaming still need
acceptance with your own account. Screenshots use clearly labeled sample data.
Kite provides market data only; no Kite order execution or INR portfolio/paper
valuation is included. Charts refresh through REST; watchlist quotes use ticks.
Indian holiday calendars and exchange-specific Pine session semantics remain
unmodeled. Background Login Items and iCloud require separate Apple signing and
entitlements. Automatic in-app replacement is disabled; update manually from
FakingView releases.
