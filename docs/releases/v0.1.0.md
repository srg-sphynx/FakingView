FakingView 0.1.0 is the first stable release for Apple Silicon Macs running macOS 14 or newer.

Download **FakingView-v0.1.0-macos-arm64.dmg**, open it, and drag **FakingView** into **Applications**. Compare the download's SHA-256 with **SHA256SUMS.txt** before opening it. A ZIP of the same application is also available.

The app includes read-only market data for Kite Connect, INDmoney and Groww. Provider access requires your own eligible account and credentials. Live access and market-data entitlements depend on your account and have not been independently verified for this release.

This release incorporates selected fixes from [DegenView v0.6.0-rc.32](https://github.com/degenview/degenview/releases/tag/v0.6.0-rc.32) and [v0.6.0-rc.33](https://github.com/degenview/degenview/releases/tag/v0.6.0-rc.33).

- Pine function and loop scopes resolve shadowed variables correctly. Higher-timeframe requests replay the relevant code, and alerts fire only from the chart's own run.
- Charts that build a candle from shorter intervals merge live and historical data more accurately. Prices below 1 show more significant digits.

The app ships without Apple Developer ID signing or notarization. macOS may show a security notice on first launch. Background alerts use the foreground fallback.

See the [installation and provider setup guide](https://github.com/srg-sphynx/FakingView/blob/v0.1.0/docs/getting-started.md). The corresponding GPL-3.0-only source is attached as **FakingView-v0.1.0-source.tar.gz**.
